1. 快速上手

第一次打开 App，会依次看到 5 页引导（拍照添加、智能偏移提醒、智能排序批次、用药记录、多药箱管理）。右上角「跳过」可直接进入，最后一页点「开始使用」进入主界面。

1
允许通知：首次添加药品时会弹出「通知」请求，请点「允许」。用药提醒完全依赖此权限。
2
确认药箱：系统已为你建好一个名叫「本人」的药箱，可直接使用，也可在「管理」里改名（比如改成你的名字）。
3
添加药品：底部切到「药箱」页 → 右下角「+」→ 拍照识别或手动录入。
4
开始打卡：到用药时间，「今日」页会出现待办卡片，点一下即可打卡。
💡 底部共三个标签：今日（当天打卡）、药箱（管理药品）、数据（历史与统计）。

2. 药箱管理

「药箱」用来给家人或不同场景分组管理药品。每个药箱里的药品、提醒、记录互不影响。

2.1 切换药箱

在「药箱」页顶部标签栏左右滑动，点某个标签即可进入该药箱。

2.2 管理药箱

点左上角「管理」：

  • 新建：点「+」，输入名称（如「妈妈」「爸爸」）。
  • 重命名：点药箱右侧的编辑图标改名。
  • 关闭（封存）：临时停用整个药箱，里面的药品和提醒全部暂停，随时可重新打开。
  • 删除：删除药箱，其中的药品会移入「回收站」。

2.3 关于「本人」药箱

系统默认建好「本人」药箱。可以改名（比如改成你的名字），改名后不影响任何功能。免费会员只有一个药箱；PRO 会员最多 10 个。

2.4 回收站

被删除的药箱/药品会进入「回收站」，可恢复或彻底删除。彻底删除后不可恢复。

⚠️ 关闭药箱后，该药箱的提醒会停止；重新打开后自动恢复。删除药箱前请确认不需要其中的药品。

3. 添加药品

3.1 两种方式

  • 拍照识别：对准药盒正面拍摄，自动识别药名、剂量、单位（需要相机权限）。识别结果可手动修正。
  • 手动录入：手动填写所有信息。

3.2 信息字段

  • 药品名称（必填）：如「阿莫西林胶囊」。
  • 自定义名（可选）：起个易记的别名，如「老爸的降压药」，列表会优先显示别名。
  • 规格 / 厂家（可选）：记录药品规格（如「0.25g×24粒」）与生产厂家。
  • 照片（可选）：可添加多张药盒照片。
  • 有效期：药品到期日，用于临期/过期提醒（详见第 6 章）。

3.3 第一次添加 = 第一批次

第一次添加药品时填写的「库存数量 + 有效期」会自动成为该药品的第一批次。之后再次购买（补货）会在详情页新增批次，各自管理有效期与用法用量（详见第 8 章）。

3.4 注意事项

  • 有效期要填准确，临期提醒依赖它。
  • 剂量和单位要准确，打卡会按它扣库存。
  • 用药时间决定提醒时刻，请按医嘱设置。
💡 免费会员最多 3 款药品、同时开启 1 个提醒；PRO 不限。

4. 用法用量怎么填

这一项最容易被填错，请仔细阅读。

4.1 每次用量 + 单位

  • 每次用量：吃一次的量，用数字填写，如「1」「0.5」「5」。
  • 单位：选择「片 / 粒 / 胶囊 / 支 / 袋 / 瓶 / 毫升 / 克 / 毫克」等。
  • 例如：每次 1 片、每次 5 毫升、每次 0.5 片（半片）。

4.2 用药时间

每天吃几次、几点吃。例如每天两次 → 「08:00、20:00」。时间点决定提醒响起的时刻，请按医嘱填写。

4.3 用餐要求

可选「餐前 / 餐后 / 空腹 / 无要求 / 遵医嘱」，用于在卡片上提示吃饭时间，不影响提醒本身。

4.4 每次用量可以不同（进阶）

如果一天内不同时间点的用量不一样（比如早 1 片、晚 2 片），可开启「差异化用量」，为每个时间点分别填写用量。

4.5 常见错误

  • 把「每天总量」填成「每次用量」——例如一天共 3 片，却填了「每次 3 片」。
  • 单位选错，导致库存扣减不准。
💡 拿不准时，请以药品说明书或医生处方为准。

5. 用药周期与结束日期

「用药周期」用于限定吃多久，比如「连续服药 7 天」。

5.1 开始日期

从这一天起开始产生提醒。默认是今天，可改成未来的某天。

5.2 结束日期

到这一天为止自动停止提醒。疗程结束（如「吃 7 天」）时非常有用——到期后 App 会自动停用该药，不会继续提醒。

5.3 「一直提醒」是什么意思？

如果选择「一直提醒」，表示没有结束日期，App 会一直按设定时间提醒，直到你手动停用。适合长期服用的慢性病药物（如降压药）。

5.4 举例

  • 短期疗程：感冒药「吃 5 天」→ 开始日期=今天，结束日期=第 5 天。
  • 长期服用：降压药 → 选「一直提醒」，长期每天提醒。
⚠️ 结束日期一旦到了，药品会显示「周期结束」并自动停止提醒。如需继续吃，请重新启用并更新周期。

6. 有效期、临期与过期

「有效期」是药品本身的到期日（印在药盒上），和「用药周期」（吃多久）是两个不同的概念。

6.1 有效期怎么填

按药盒上印刷的「有效期至 / EXP」填写。填错会导致临期/过期提醒不准。

6.2 临期与过期的显示

  • 临期：有效期在 30 天内，药箱卡片右上角会显示「临期」角标。
  • 即将过期：某批次在 7 天内到期，批次详情会标「即将过期」；10 天内会以红色紧急样式显示。
  • 已过期：过了有效期，会显示「已过期」，且该批次不再参与库存扣减（不会让你吃到过期的药）。

6.3 过期后会发生什么

  • 某个批次过期 → 该批次被跳过，自动改用下一个未过期的批次。
  • 全部批次都过期 → 药品会自动停用（状态显示「已过期」），不再提醒。
⚠️ 请勿服用已过期的药品。补进新批次的药并更新有效期后，提醒会自动恢复。

7. 药品状态：在用 / 停用 / 主动停用

每款药品都有一个「状态」，决定它现在是否提醒、是否扣库存。

7.1 在用（启用）

药品正在正常使用：会按时提醒、打卡会扣库存。这是默认的正常状态。

7.2 停用（暂停）

药品暂时停止：不再提醒，但数据、库存、历史记录都完整保留，随时可重新「启用」。停用有两种：

  • 主动停用：你自己手动左滑「停用」，或编辑时关闭。比如某药暂时停吃。
  • 自动停用：系统在「周期结束 / 库存用完 / 全部过期」时自动停用，卡片上会显示对应原因。

7.3 状态标签怎么看

  • 主动停用：你手动停的。
  • 周期结束：到了结束日期，疗程结束了。
  • 库存不足 / 库存低：剩余不够一次用量了。
  • 已过期：所有批次都过期了。
  • 未到时间：还没到开始日期。

7.4 怎么启用

停用的药品，在药箱详情页或左滑菜单里点「启用」即可恢复提醒。若因库存/过期被停用，需先补货或更新有效期。

8. 库存与批次

「批次」是同一药品的不同次购买/入库记录。同一款药，不同批次可能有不同的有效期和用法用量。

8.1 第一批次

第一次添加药品时填的「库存数量 + 有效期」就是第一批次。

8.2 补货（新增批次）

之后再次购买同一款药，在详情页点「补充库存」新增一个批次，单独填写数量、有效期（可不同）。

8.3 先到期先用（FIFO）

系统自动按有效期最早的批次优先扣减，先到期的先用，减少浪费。你也可以手动指定某个批次为「在用批次」（绿色圆点）。

8.4 批次切换提示

当前批次用完、自动切换到下一批时，如果用法用量变了（比如新批次剂量不同），App 会弹出提示告知你「用药时间/用量已改变」，请留意。

8.5 低库存提醒

剩余库存只够 3 天用量（或只剩最后 1 次）时，卡片会显示「库存低」并标红，提醒你及时补货。

⚠️ 全部批次用完或过期，药品会自动停用。

9. 用药提醒与稍后提醒

9.1 通知权限

请在系统「设置 → 通知 → 简记药箱」允许通知，否则收不到提醒。

9.2 智能偏移提醒

开启后，通知会在设定时间附近随机浮动几分钟（范围可设 5/10/15/30 分钟），避免形成固定习惯的疲劳感。也可关闭。

9.3 稍后提醒（再响一次）

通知弹出后，若暂时不方便吃药，点「稍后提醒」，App 会在 15 分钟后再提醒一次。最多可稍后 2 次，之后就不再重复，避免过度打扰。

9.4 锁屏隐私

在「设置 → 通知」开启「隐藏药品名称」，锁屏通知上就不显示药名，保护隐私。

9.5 提醒没响？

  • 检查系统通知权限是否关闭；
  • 检查药品是否「在用」（停用/关闭药箱会暂停）；
  • 检查用药时间、开始/结束日期是否正确。

10. 今日打卡：打卡 / 跳过 / 忘记 / 忽略

「今日」页按时间列出当天所有待办。下面解释每个操作的含义。

10.1 打卡（记录服药）

点「打卡」表示你已经吃了药，系统会自动扣减一次库存，并把这次记为按时/提前/延后（由实际时间自动判定：±30 分钟内算「按时」）。

10.2 跳过（这次不吃）

点「跳过」表示这次决定不吃（比如医生让暂停），不扣库存，统计里记为「跳过」。

10.3 忘记（忘了吃）

点「忘记」表示忘了吃药，不扣库存，统计里记为「忘记」。用于如实记录。

10.4 忽略（今天不提醒这条）

左滑「忽略」表示今天不再管这条（比如今天不需要吃），不计入完成，也不计入遗漏，即从统计里排除。

10.5 取消

在弹窗里点「取消」就是关闭菜单、不做任何操作，状态保持不变。

10.6 一键打卡

点顶部「一键打卡」可把当天所有待办批量标记为已打卡。

⚠️ 打卡会扣库存；库存不足一次用量时会拦截并提示补货。误操作可到「数据 → 打卡记录」重新打卡/删除，会自动退回库存。

11. 历史记录与统计

11.1 打卡记录

「数据 → 打卡记录」按天查看，顶部月历可跳转日期。点某条记录可：

  • 补录：对漏打的记录补打卡（会扣库存）。
  • 重新打卡：撤销原记录并退回库存，再重新打卡。
  • 删除：删除记录并退回库存。
  • 标记为忘记：把待办标记为「忘记」。

11.2 哪天可以改/删？

过去（含今天）的打卡记录一般都可以重新打卡/删除（会退回库存）；未来的日期是「计划用药」，只能查看，不能提前操作。

11.3 删除扣库存吗？

删除/重新打卡会退回库存（把当时扣的加回来）。「跳过/忘记/忽略」本就不扣库存，所以也没有退回。

11.4 用药统计

饼图 + 总打卡 / 药品种类 / 按时率 / 批次消耗 / 打卡时段分布。顶部可切换「本月 / 本年 / 全部」。

11.5 导出报表（PRO）

导出定制化 PDF 用药报告（统计概览、用药清单、打卡明细、批次消耗）。注意：报告只统计所选时间范围内的记录。

12. 数据备份与恢复

12.1 本地备份（JSON）

  • 导出：生成 JSON 备份文件，可保存到「文件」或分享。
  • 导入：选择之前的 JSON 文件恢复，会覆盖当前全部数据，操作前请先备份。

12.2 免费会员只能备份「本人」药箱

免费会员只有一个药箱，所以导出/导入都只针对这一个药箱。注意：即使你把这个默认药箱改名了（比如从「本人」改成你的名字），导出/导入依然针对你当前的那一个药箱，不受名字影响。多药箱备份需要 PRO。

12.3 iCloud 数据备份（PRO）

「设置 → iCloud 同步 → 数据备份」：

  • 立即备份：手动备份到 iCloud Drive。
  • 恢复：左滑备份 → 恢复。
  • 删除：左滑 → 删除。
  • 分享：右滑 → 分享/保存备份文件。

每台设备最多保留 20 份备份，超出自动删最旧。

12.4 iCloud 自动同步（PRO）

开启后换设备/重装，登录同一 iCloud 账号自动同步药品与设置。自动同步没有设备数量限制；「20 份」仅指每台设备的备份快照。

12.5 恢复/重置注意事项

  • 「恢复」会覆盖当前全部数据，恢复前建议先备份。
  • 「清空本地数据」不可撤销。
⚠️ 空数据时不会生成备份文件，避免产生无效的空文件。

14. 设置与崩溃日志

14.1 常用设置

  • 主题色 / 文字大小 / 外观模式：浅色、深色或跟随系统。
  • 语言：简体中文 / 繁體中文 / English / 日本語 / 跟随系统。
  • 通知：智能偏移、隐藏药名、低库存提醒、角标显示。
  • 清空数据：清空药箱与药品（保留记录）或清空全部本地数据（不可恢复）。

14.2 什么是崩溃日志？

当 App 意外闪退时，会自动在本地保存一份技术日志，用于帮助开发者排查闪退原因。这份日志不包含你的药品名称、用量等隐私内容（已自动脱敏）。你可以在「设置 → 提交崩溃」中查看或复制，主动发给开发者，帮助我们更快修复问题。如果你不发送，日志只保存在本地，不会自动上传。

15. 常见问题

15.1 数据存在哪里？

默认仅存设备本地；开启 iCloud 同步（PRO）后，通过你自己的 iCloud 私密同步，开发者无法访问。

15.2 不联网能用吗？

能。管理、打卡、提醒、统计、本地备份都无需联网；仅 iCloud 备份同步、兑换码、内购需要网络。

15.3 打卡会影响库存吗？

会，打卡自动扣一次用量；删除/重新打卡会自动退回。

15.4 免责声明

⚠️ 本 App 仅用于用药记录与提醒，不构成任何医疗建议，请务必遵医嘱用药。

💡 底部共三個標籤：今日（當天打卡）、藥箱（管理藥品）、資料（歷史與統計）。

2. 藥箱管理

「藥箱」用來給家人或不同情境分組管理藥品。每個藥箱裡的藥品、提醒、記錄互不影響。

2.1 切換藥箱

在「藥箱」頁頂部標籤列左右滑動，點某個標籤即可進入該藥箱。

2.2 管理藥箱

點左上角「管理」：

  • 新增：點「+」，輸入名稱（如「媽媽」「爸爸」）。
  • 重新命名：點藥箱右側的編輯圖示改名。
  • 關閉（封存）：暫時停用整個藥箱，裡面的藥品和提醒全部暫停，隨時可重新開啟。
  • 刪除：刪除藥箱，其中的藥品會移入「垃圾桶」。

2.3 關於「本人」藥箱

系統預設建好「本人」藥箱。可以改名（例如改成你的名字），改名後不影響任何功能。免費會員只有一個藥箱；PRO 會員最多 10 個。

2.4 垃圾桶

被刪除的藥箱／藥品會進入「垃圾桶」，可還原或徹底刪除。徹底刪除後無法復原。

⚠️ 關閉藥箱後，該藥箱的提醒會停止；重新開啟後自動還原。刪除藥箱前請確認不需要其中的藥品。

3. 新增藥品

3.1 兩種方式

  • 拍照辨識：對準藥盒正面拍攝，自動辨識藥名、劑量、單位（需要相機權限）。辨識結果可手動修正。
  • 手動輸入：手動填寫所有資訊。

3.2 資訊欄位

  • 藥品名稱（必填）：如「阿莫西林膠囊」。
  • 自訂名稱（選填）：起個好記的別名，如「老爸的降血壓藥」，列表會優先顯示別名。
  • 規格／廠商（選填）：記錄藥品規格（如「0.25g×24粒」）與生產廠商。
  • 照片（選填）：可新增多張藥盒照片。
  • 有效期限：藥品到期日，用於臨期／過期提醒（詳見第 6 章）。

3.3 第一次新增 = 第一批次

第一次新增藥品時填寫的「庫存數量＋有效期限」會自動成為該藥品的第一批次。之後再次購買（補貨）會在詳情頁新增批次，各自管理有效期限與用法用量（詳見第 8 章）。

3.4 注意事項

  • 有效期限要填準確，臨期提醒依賴它。
  • 劑量和單位要準確，打卡會按它扣庫存。
  • 用藥時間決定提醒時刻，請按醫囑設定。
💡 免費會員最多 3 款藥品、同時開啟 1 個提醒；PRO 不限。

4. 用法用量怎麼填

這一項最容易填錯，請仔細閱讀。

4.1 每次用量＋單位

  • 每次用量：吃一次的量，用數字填寫，如「1」「0.5」「5」。
  • 單位：選擇「片／粒／膠囊／支／包／瓶／毫升／公克／毫克」等。
  • 例如：每次 1 片、每次 5 毫升、每次 0.5 片（半片）。

4.2 用藥時間

每天吃幾次、幾點吃。例如每天兩次 → 「08:00、20:00」。時間點決定提醒響起的時刻，請按醫囑填寫。

4.3 用餐要求

可選「餐前／餐後／空腹／無要求／遵醫囑」，用於在卡片上提示吃藥時機，不影響提醒本身。

4.4 每次用量可以不一樣（進階）

如果一天內不同時間點的用量不同（例如早 1 片、晚 2 片），可開啟「差異化用量」，為每個時間點分別填寫用量。

4.5 常見錯誤

  • 把「每天總量」填成「每次用量」——例如一天共 3 片，卻填了「每次 3 片」。
  • 單位選錯，導致庫存扣減不準。
💡 拿不準時，請以藥品說明書或醫師處方為準。

5. 用藥週期與結束日期

「用藥週期」用於限定吃多久，例如「連續服藥 7 天」。

5.1 開始日期

從這一天起開始產生提醒。預設是今天，可改成未來的某天。

5.2 結束日期

到這一天為止自動停止提醒。療程結束（如「吃 7 天」）時非常有用——到期後 App 會自動停用該藥，不會繼續提醒。

5.3 「一直提醒」是什麼意思？

如果選擇「一直提醒」，表示沒有結束日期，App 會一直按設定時間提醒，直到你手動停用。適合長期服用的慢性病藥物（如降血壓藥）。

5.4 舉例

  • 短期療程：感冒藥「吃 5 天」→ 開始日期=今天，結束日期=第 5 天。
  • 長期服用：降血壓藥 → 選「一直提醒」，長期每天提醒。
⚠️ 結束日期一到，藥品會顯示「週期結束」並自動停止提醒。如需繼續吃，請重新啟用並更新週期。

6. 有效期限、臨期與過期

「有效期限」是藥品本身的到期日（印在藥盒上），和「用藥週期」（吃多久）是兩個不同的概念。

6.1 有效期限怎麼填

按藥盒上印刷的「有效期限至／EXP」填寫。填錯會導致臨期／過期提醒不準。

6.2 臨期與過期的顯示

  • 臨期：有效期限在 30 天內，藥箱卡片右上角會顯示「臨期」角標。
  • 即將過期：某批次在 7 天內到期，批次詳情會標「即將過期」；10 天內會以紅色緊急樣式顯示。
  • 已過期：過了有效期限，會顯示「已過期」，且該批次不再參與庫存扣減（不會讓你吃到過期的藥）。

6.3 過期後會發生什麼

  • 某個批次過期 → 該批次被跳過，自動改用下一個未過期的批次。
  • 全部批次都過期 → 藥品會自動停用（狀態顯示「已過期」），不再提醒。
⚠️ 請勿服用已過期的藥品。補進新批次的藥並更新有效期限後，提醒會自動還原。

7. 藥品狀態：使用中／停用／主動停用

每款藥品都有一個「狀態」，決定它現在是否提醒、是否扣庫存。

7.1 使用中（啟用）

藥品正在正常使用：會按時提醒、打卡會扣庫存。這是預設的正常狀態。

7.2 停用（暫停）

藥品暫時停止：不再提醒，但資料、庫存、歷史記錄都完整保留，隨時可重新「啟用」。停用有兩種：

  • 主動停用：你自己手動左滑「停用」，或編輯時關閉。例如某藥暫時停吃。
  • 自動停用：系統在「週期結束／庫存用完／全部過期」時自動停用，卡片上會顯示對應原因。

7.3 狀態標籤怎麼看

  • 主動停用：你手動停的。
  • 週期結束：到了結束日期，療程結束了。
  • 庫存不足／庫存低：剩餘不夠一次用量了。
  • 已過期：所有批次都過期了。
  • 未到時間：還沒到開始日期。

7.4 怎麼啟用

停用的藥品，在藥箱詳情頁或左滑選單裡點「啟用」即可還原提醒。若因庫存／過期被停用，需先補貨或更新有效期限。

8. 庫存與批次

「批次」是同一藥品的不同次購買／入庫記錄。同一款藥，不同批次可能有不同的有效期限和用法用量。

8.1 第一批次

第一次新增藥品時填的「庫存數量＋有效期限」就是第一批次。

8.2 補貨（新增批次）

之後再次購買同一款藥，在詳情頁點「補充庫存」新增一個批次，單獨填寫數量、有效期限（可不同）。

8.3 先到期先用（FIFO）

系統自動按有效期限最早的批次優先扣減，先到期的先用，減少浪費。你也可以手動指定某個批次為「使用中批次」（綠色圓點）。

8.4 批次切換提示

目前批次用完、自動切換到下一批時，如果用法用量變了（例如新批次劑量不同），App 會跳出提示告知你「用藥時間／用量已改變」，請留意。

8.5 低庫存提醒

剩餘庫存只夠 3 天用量（或只剩最後 1 次）時，卡片會顯示「庫存低」並標紅，提醒你及時補貨。

⚠️ 全部批次用完或過期，藥品會自動停用。

9. 用藥提醒與稍後提醒

9.1 通知權限

請在系統「設定 → 通知 → 簡記藥箱」允許通知，否則收不到提醒。

9.2 智慧偏移提醒

開啟後，通知會在設定時間附近隨機浮動幾分鐘（範圍可設 5/10/15/30 分鐘），避免形成固定習慣的疲勞感。也可關閉。

9.3 稍後提醒（再響一次）

通知跳出後，若暫時不方便吃藥，點「稍後提醒」，App 會在 15 分鐘後再提醒一次。最多可稍後 2 次，之後就不再重複，避免過度打擾。

9.4 鎖定畫面隱私

在「設定 → 通知」開啟「隱藏藥品名稱」，鎖定畫面通知就不顯示藥名，保護隱私。

9.5 提醒沒響？

  • 檢查系統通知權限是否關閉；
  • 檢查藥品是否「使用中」（停用／關閉藥箱會暫停）；
  • 檢查用藥時間、開始／結束日期是否正確。

10. 今日打卡：打卡／跳過／忘記／忽略

「今日」頁按時間列出當天所有待辦。下面解釋每個操作的含義。

10.1 打卡（記錄服藥）

點「打卡」表示你已經吃了藥，系統會自動扣減一次庫存，並把這次記為按時／提前／延後（由實際時間自動判定：±30 分鐘內算「按時」）。

10.2 跳過（這次不吃）

點「跳過」表示這次決定不吃（例如醫生讓暫停），不扣庫存，統計裡記為「跳過」。

10.3 忘記（忘了吃）

點「忘記」表示忘了吃藥，不扣庫存，統計裡記為「忘記」。用於如實記錄。

10.4 忽略（今天不提醒這條）

左滑「忽略」表示今天不再管這條（例如今天不需要吃），不計入完成，也不計入遺漏，即從統計裡排除。

10.5 取消

在彈窗裡點「取消」就是關閉選單、不做任何操作，狀態保持不變。

10.6 一鍵打卡

點頂部「一鍵打卡」可把當天所有待辦批次標記為已打卡。

⚠️ 打卡會扣庫存；庫存不足一次用量時會攔截並提示補貨。誤操作可到「資料 → 打卡記錄」重新打卡／刪除，會自動退回庫存。

11. 歷史記錄與統計

11.1 打卡記錄

「資料 → 打卡記錄」按天查看，頂部月曆可跳轉日期。點某條記錄可：

  • 補錄：對漏打的記錄補打卡（會扣庫存）。
  • 重新打卡：撤銷原記錄並退回庫存，再重新打卡。
  • 刪除：刪除記錄並退回庫存。
  • 標記為忘記：把待辦標記為「忘記」。

11.2 哪天可以改／刪？

過去（含今天）的打卡記錄一般都可以重新打卡／刪除（會退回庫存）；未來的日期是「計畫用藥」，只能查看，不能提前操作。

11.3 刪除扣庫存嗎？

刪除／重新打卡會退回庫存（把當時扣的加回來）。「跳過／忘記／忽略」本就不扣庫存，所以也沒有退回。

11.4 用藥統計

圓餅圖＋總打卡／藥品種類／按時率／批次消耗／打卡時段分佈。頂部可切換「本月／本年／全部」。

11.5 匯出報表（PRO）

匯出客製化 PDF 用藥報告（統計概覽、用藥清單、打卡明細、批次消耗）。注意：報告只統計所選時間範圍內的記錄。

12. 資料備份與復原

12.1 本地備份（JSON）

  • 匯出：產生 JSON 備份檔，可儲存到「檔案」或分享。
  • 匯入：選擇之前的 JSON 檔還原，會覆蓋目前全部資料，操作前請先備份。

12.2 免費會員只能備份「本人」藥箱

免費會員只有一個藥箱，所以匯出／匯入都只針對這一個藥箱。注意：即使你把這個預設藥箱改名了（例如從「本人」改成你的名字），匯出／匯入依然針對你目前的那一個藥箱，不受名字影響。多藥箱備份需要 PRO。

12.3 iCloud 資料備份（PRO）

「設定 → iCloud 同步 → 資料備份」：

  • 立即備份：手動備份到 iCloud Drive。
  • 復原：左滑備份 → 復原。
  • 刪除：左滑 → 刪除。
  • 分享：右滑 → 分享／儲存備份檔。

每台裝置最多保留 20 份備份，超出自動刪最舊。

12.4 iCloud 自動同步（PRO）

開啟後換裝置／重裝，登入同一 iCloud 帳號自動同步藥品與設定。自動同步沒有裝置數量限制；「20 份」僅指每台裝置的備份快照。

12.5 復原／重置注意事項

  • 「復原」會覆蓋目前全部資料，復原前建議先備份。
  • 「清除本地資料」無法撤銷。
⚠️ 無資料時不會產生備份檔，避免產生無效的空檔。

3. Adding a Medication

3.1 Two ways

  • Photo OCR — photograph the packaging front; name/dose/unit are auto-detected (camera permission required). You can correct the results.

  • Expiry — the expiration date, used for expiring/expired alerts (see chapter 6).

3.3 First add = first batch

The "stock + expiry" you enter when first adding becomes the first batch. Later purchases (restock) add new batches with their own expiry and dosage (see chapter 8).

3.4 Tips

  • Enter expiry accurately — expiring alerts depend on it.
  • Enter dose/unit accurately — stock deduction uses it.
  • Times set the reminder schedule — follow your prescription.
💡 Free: 3 meds, 1 active reminder. PRO: unlimited.

4. How to Enter Dosage

This is the most common source of mistakes — read carefully.

4.1 Amount + unit

  • Amount: the amount per single dose, as a number (1, 0.5, 5).
  • Unit: tablet / capsule / vial / sachet / bottle / mL / g / mg, etc.
  • Examples: 1 tablet, 5 mL, 0.5 tablet (half).

4.2 Times

How many times per day, and at what time — e.g. "08:00, 20:00" for twice daily. Times determine when reminders fire; follow your prescription.

4.3 Meal

Before/after meal, on empty stomach, no requirement, or as directed — a hint on the card; it doesn't change the reminder itself.

4.4 Different dose per time (advanced)

If different times of day have different amounts (e.g. 1 in the morning, 2 at night), enable "per-time dosage" and set each separately.

4.5 Common mistakes

  • Entering the daily total as the per-dose amount (e.g. "3 tablets" when it's 3 per day, 1 per dose).
  • Choosing the wrong unit, which makes stock deduction inaccurate.
💡 When unsure, follow the package insert or your prescription.

5. Course Period & End Date

The "course period" limits how long to take a medication — e.g. "take for 7 days".

5.1 Start date

Reminders begin on this date. Defaults to today; can be set in the future.

5.2 End date

Reminders stop on this date. Useful for courses — once reached, the app auto-deactivates the med and stops reminding.

5.3 What does "Always remind" mean?

Choosing "Always remind" means no end date — the app keeps reminding at the set times until you deactivate manually. Best for long-term meds (e.g. blood-pressure medication).

5.4 Examples

  • Short course: cold medicine "5 days" → start = today, end = day 5.
  • Long-term: blood-pressure med → "Always remind".
⚠️ Once the end date passes, the med shows "Course ended" and stops reminding. To resume, reactivate and update the period.

6. Expiry, Expiring Soon & Expired

"Expiry" is the medication's own expiration date (printed on the box) — different from the "course period" (how long you take it).

6.1 How to enter expiry

Use the "EXP / valid until" printed on the packaging. Entering it wrong makes expiring/expired alerts inaccurate.

6.2 How expiring/expired is shown

  • Expiring soon: expiry within 30 days — a "expiring" badge appears on the medbox card.
  • About to expire: a batch expiring within 7 days is marked "expiring soon"; within 10 days it turns red/urgent.
  • Expired: past its expiry, shown as "expired"; that batch is skipped for stock (so you never consume expired medicine).

6.3 What happens after expiry

  • One batch expired → it's skipped and the next unexpired batch is used.
  • All batches expired → the med is auto-deactivated (status "Expired") and stops reminding.
⚠️ Never take expired medication. After adding a new batch and updating the expiry, reminders resume automatically.

7. Medication Status: Active / Deactivated

Each medication has a "status" that decides whether it reminds and deducts stock.

7.1 Active

The med is in normal use: it reminds on schedule and punching in deducts stock. This is the default.

7.2 Deactivated (paused)

The med is paused: no reminders, but all data, stock, and history are kept; reactivate anytime. Two kinds:

  • Manually deactivated: you swipe-left "Deactivate", or turned it off in editing.
  • Auto-deactivated: the system deactivates on "course ended / out of stock / all expired", with the reason shown on the card.

7.3 Reading the status label

  • Manually deactivated — you stopped it.
  • Course ended — the end date passed.
  • Out of stock / Low stock — not enough left for one dose.
  • Expired — all batches expired.
  • Not yet started — before the start date.

7.4 How to reactivate

Tap "Activate" on the details page or swipe menu. If it was stopped for stock/expiry, restock or update the expiry first.

8. Stock & Batches

A "batch" is a separate purchase/restock of the same medication. Different batches can have different expiry and dosage.

8.1 First batch

The "stock + expiry" entered when first adding is the first batch.

8.2 Restock (new batch)

When you buy the same med again, tap "Restock" on the details page to add a batch with its own quantity and expiry.

8.3 First-expiry-first (FIFO)

Stock is automatically deducted from the earliest-expiring batch first, reducing waste. You can also manually mark a batch as "in use" (green dot).

8.4 Batch-switch notice

When the current batch runs out and switches to the next, if the dosage changed, the app notifies you that "time/dosage has changed" — please take note.

8.5 Low-stock alert

When stock covers only ~3 days (or just the last dose), the card shows "Low stock" in red.

⚠️ If all batches run out or expire, the med auto-deactivates.

9. Reminders & Snooze

9.1 Permission

Allow notifications in iOS Settings → Notifications → JianjiBox.

9.2 Smart offset

When on, reminders drift a few minutes around the set time (5/10/15/30 min, or off), to avoid rigid-habit fatigue.

9.3 Snooze (remind again)

When a notification appears, tap "Snooze" and the app reminds you again in 15 minutes. You can snooze at most 2 times per dose to avoid over-nagging.

9.4 Lock-screen privacy

Enable "Hide medication name" in Settings → Notifications to hide names on the lock screen.

9.5 Not firing?

  • Check notification permission.
  • Check the med is "active" (deactivated/closed box pauses it).
  • Check the times and start/end dates.

10. Punching In: Log / Skip / Missed / Ignore

The "Today" tab lists all of today's doses. Here's what each action means.

10.1 Log (record dose taken)

Tap "Log" to mean you took the medicine. The app deducts one dose of stock and records it as on-time/early/late (auto-judged by actual time; within ±30 min counts as "on time").

10.2 Skip (won't take this one)

Tap "Skip" to mean you're not taking this dose (e.g. doctor said to pause). No stock deducted; recorded as "skipped".

10.3 Missed (forgot)

Tap "Missed" to mean you forgot. No stock deducted; recorded as "missed".

10.4 Ignore (don't track this today)

Swipe-left "Ignore" to mean skip tracking this one today. Not counted as done, not counted as missed — excluded from stats.

10.5 Cancel

"Cancel" just closes the menu without changing anything.

10.6 Punch all

Tap "Punch all" to mark every pending dose as logged at once.

⚠️ Logging deducts stock; if stock is below one dose, it's blocked with a restock prompt. Mistakes can be fixed in Data → History (re-log/delete auto-returns stock).

2. 薬箱の管理

「薬箱」は家族やシーンごとに薬をグループ化するためのものです。各薬箱の薬・リマインダー・記録は互いに影響しません。

2.1 切り替え

「薬箱」ページ上部のタブを左右にスワイプし、タップして切り替えます。

2.2 管理

左上の「管理」をタップ：

  • 新規作成：「+」をタップして名前を入力（例：「お母さん」）。
  • 名前変更：編集アイコンで変更。
  • 閉じる（封鎖）：その薬箱を一時停止し、中の薬とリマインダーを全て停止。いつでも再開できます。
  • 削除：薬箱を削除し、中の薬は「ゴミ箱」へ移動。

2.3 「本人」の薬箱について

「本人」の薬箱は自動作成され、名前を変更できます（例：自分の名前に）。変更しても機能に影響はありません。無料会員は1つ、PRO会員は最大10個まで。

2.4 ゴミ箱

削除した薬箱・薬は「ゴミ箱」に入り、復元または完全削除できます。完全削除すると復元できません。

⚠️ 薬箱を閉じるとリマインダーが停止し、再度開くと復帰します。削除前に中の薬が不要か確認してください。

3. 薬の追加

3.1 2つの方法

  • 写真OCR：薬のパッケージ正面を撮影すると、薬品名・用量・単位を自動認識（カメラ権限が必要）。結果は手動で修正できます。
  • 手動入力：すべて手入力します。

3.2 入力項目

  • 薬品名（必須）：例「アモキシシリンカプセル」。
  • カスタム名（任意）：覚えやすい別名（例「父の血圧の薬」）。一覧では別名が優先表示されます。
  • 規格・メーカー（任意）：規格（例「0.25g×24粒」）とメーカー。
  • 写真（任意）：パッケージ写真を複数枚。
  • 有効期限：薬の期限日。期限間近・期限切れの通知に使われます（第6章参照）。

3.3 初回追加 = 最初のロット

初回に追加した「在庫数＋有効期限」は、その薬の最初のロットになります。その後、同じ薬を買い足すと詳細ページでロットを追加し、それぞれ有効期限と用法・用量を管理できます（第8章参照）。

3.4 注意点

  • 有効期限は正確に入力（期限通知に影響）。
  • 用量・単位は正確に入力（在庫の減算に影響）。
  • 服用時刻はリマインダーの時刻になるので、処方どおりに設定。
💡 無料会員は薬3種類・リマインダー1件まで。PROは無制限。

4. 用法・用量の入力方法

ここは間違いやすい項目なので、よくお読みください。

4.1 1回の用量＋単位

  • 1回の用量：1回に服用する量を数字で入力（例：1、0.5、5）。
  • 単位：「錠・粒・カプセル・本・包・ボトル・mL・g・mg」などから選択。
  • 例：1回1錠、1回5mL、1回0.5錠（半錠）。

4.2 服用時刻

1日何回・何時に服用するか。例：1日2回なら「08:00、20:00」。時刻がリマインダーのタイミングになるので、処方どおりに。

4.3 食事

「食前・食後・空腹時・指定なし・医師の指示に従う」から選択。カード上に服用タイミングを表示するもので、リマインダー自体は変わりません。

4.4 時刻ごとに用量を変える（上級）

時間帯によって用量が異なる場合（例：朝1錠、夜2錠）は「時刻別用量」をオンにして、各時刻の用量を個別に設定できます。

4.5 よくある間違い

  • 「1日の合計」を「1回の用量」として入力（例：1日合計3錠なのに「1回3錠」と入力）。
  • 単位を間違えると在庫の減算が不正確になります。
💡 迷ったら、薬の説明書または医師の処方を優先してください。

5. 服用期間と終了日

「服用期間」は、どれくらいの期間服用するかを決めるもので、例として「7日間服用」があります。

5.1 開始日

この日からリマインダーを開始します。既定は今日で、未来の日に変更できます。

5.2 終了日

この日でリマインダーを自動停止します。コース（例：7日間）が終わると、その薬は自動で休止され、通知が続きません。

5.3 「常に通知」とは？

「常に通知」を選ぶと、終了日なしとなり、設定した時刻にずっと通知し続けます（手動で休止するまで）。長期間服用する慢性疾患の薬（血圧の薬など）向けです。

5.4 例

  • 短期コース：風邪薬「5日間」→ 開始日＝今日、終了日＝5日目。
  • 長期：血圧の薬 → 「常に通知」を選択。
⚠️ 終了日を過ぎると「期間終了」と表示され、リマインダーが停止します。続けて服用する場合は、再開して期間を更新してください。

6. 有効期限・期限間近・期限切れ

「有効期限」は薬自体の期限日（パッケージに印字）で、「服用期間」（どれだけ服用するか）とは別の概念です。

6.1 有効期限の入力方法

パッケージに印字された「EXP／有効期限」を入力してください。間違えると期限間近・期限切れの通知が不正確になります。

6.2 期限間近・期限切れの表示

  • 期限間近：有効期限が30日以内。薬箱カード右上に「期限間近」バッジが表示されます。
  • まもなく期限切れ：ロットの期限が7日以内の場合は「まもなく期限切れ」と表示。10日以内は赤い緊急表示になります。
  • 期限切れ：期限を過ぎると「期限切れ」と表示され、そのロットは在庫の減算対象から外れます（期限切れの薬を服用させません）。

6.3 期限切れ後の動作

  • 一部のロットが期限切れ → そのロットはスキップされ、次に未期限切れのロットが使われます。
  • すべてのロットが期限切れ → その薬は自動休止（状態「期限切れ」）となり、通知されません。
⚠️ 期限切れの薬は服用しないでください。新しいロットを追加して有効期限を更新すると、リマインダーが自動で再開します。

7. 薬の状態：使用中／休止／手動休止

各薬には「状態」があり、現在通知するか・在庫を減らすかを決めます。

7.1 使用中（有効）

正常に使用中：時刻どおりに通知し、記録すると在庫が減ります。これが既定の状態です。

7.2 休止（一時停止）

一時停止：通知しませんが、データ・在庫・履歴はすべて保持され、いつでも再開できます。休止には2種類あります：

  • 手動休止：自分で左スワイプの「休止」を選ぶか、編集でオフにした場合。
  • 自動休止：「期間終了／在庫切れ／全ロット期限切れ」でシステムが自動休止し、カードに理由が表示されます。

7.3 状態ラベルの見方

  • 手動休止：自分で停止した。
  • 期間終了：終了日を過ぎてコースが終了。
  • 在庫不足／在庫わずか：1回分に足りない。
  • 期限切れ：全ロットが期限切れ。
  • 開始前：開始日より前。

7.4 再開方法

休止中の薬は、詳細ページまたは左スワイプメニューで「再開」をタップすると復帰します。在庫・期限が原因の場合は、先に補充または有効期限の更新が必要です。

8. 在庫とロット

「ロット」は同じ薬の別々の購入・入庫の記録です。同じ薬でも、ロットごとに有効期限と用法・用量が異なる場合があります。

8.1 最初のロット

初回に追加した「在庫数＋有効期限」が最初のロットです。

8.2 補充（新ロット追加）

同じ薬を買い足したら、詳細ページの「在庫補充」で新しいロットを追加し、数量・有効期限を個別に入力します。

8.3 先に期限が来るものを先に使用（FIFO）

有効期限が最も早いロットから自動で在庫を減らし、無駄を減らします。手動で特定のロットを「使用中ロット」（緑の点）に指定することもできます。

8.4 ロット切り替えのお知らせ

現在のロットがなくなり次のロットに切り替わるとき、用法・用量が変わった場合（例：新ロットの用量が異なる）は「時刻／用量が変わりました」と通知されるので、ご注意ください。

8.5 在庫不足のお知らせ

在庫が約3日分（または残り1回分）になると、カードに「在庫わずか」と赤く表示され、補充を促します。

⚠️ 全ロットを使い切る・期限切れになると、薬は自動休止されます。

9. リマインダーとスヌーズ

9.1 通知権限

iOSの「設定 → 通知 → JianjiBox」で通知を許可してください。許可しないと通知が届きません。

9.2 スマートオフセット

オンにすると、通知が設定時刻の前後で数分ランダムに変動します（範囲は5/10/15/30分、またはオフ）。固定習慣による慣れを防ぎます。

9.3 スヌーズ（もう一度通知）

通知が表示されたとき、すぐに服用できない場合は「スヌーズ」をタップすると、15分後にもう一度通知します。1回につき最大2回までで、それ以上は繰り返さず、過度な通知を避けます。

9.4 ロック画面のプライバシー

「設定 → 通知」で「薬品名を隠す」をオンにすると、ロック画面に薬品名が表示されません。

9.5 通知が来ない？

  • 通知権限がオフになっていないか確認。
  • 薬が「使用中」か確認（休止・薬箱を閉じると停止）。
  • 服用時刻・開始日・終了日が正しいか確認。

10. 服薬の記録：記録／スキップ／忘れ／無視

「今日」タブには当日の未対応分が時刻順に並びます。各操作の意味を説明します。

10.1 記録（服用済みにする）

「記録」をタップすると薬を服用したことになり、在庫が1回分減ります。実際の時刻に応じて定時・早め・遅れが自動判定されます（±30分以内は「定時」）。

10.2 スキップ（今回は服用しない）

「スキップ」は今回は服用しない（例：医師の指示で休止）ことで、在庫は減らず、統計では「スキップ」として記録されます。

10.3 忘れ（飲み忘れ）

「忘れ」は飲み忘れたことを示し、在庫は減らず、統計では「忘れ」として記録されます。

10.4 無視（今日はこの項目を管理しない）

左スワイプの「無視」は今日この項目を管理しない（例：今日は不要）ことで、完了にも漏れにも数えず、統計から除外します。

10.5 キャンセル

「キャンセル」はメニューを閉じるだけで、何も変更しません。

10.6 一括記録

上部の「一括記録」で、当日の未対応分をまとめて記録済みにできます。

⚠️ 記録すると在庫が減ります。1回分に足りない場合は補充を促されます。誤操作は「データ → 記録」で再記録・削除でき、在庫も自動で戻ります。

11. 履歴と統計

11.1 服薬記録

「データ → 記録」は日別表示で、上部の月カレンダーで日付を移動できます。記録をタップすると：

  • 追記：飲み忘れた分を記録（在庫が減る）。
  • 再記録：元の記録を取り消して在庫を戻し、再度記録。
  • 削除：記録を削除して在庫を戻す。
  • 忘れに変更：未対応を「忘れ」に変更。

11.2 いつ編集・削除できる？

過去（今日含む）の記録は通常、再記録・削除できます（在庫が戻る）。未来の日付は「予定」なので閲覧のみで、事前操作はできません。

11.3 削除で在庫は減る？

いいえ。削除・再記録では在庫が戻ります。スキップ・忘れ・無視は元々在庫を減らさないため、戻るものもありません。

11.4 統計

円グラフ＋総記録／薬の種類／定時率／ロット消費／時間帯分布。上部で「今月／今年／すべて」を切り替え。

11.5 レポート出力（PRO）

カスタムPDF（概要、薬の一覧、記録明細、ロット使用）を出力。選択した期間のみが対象です。

12. バックアップと復元

12.1 ローカルバックアップ（JSON）

  • 出力：JSONファイルを生成し、「ファイル」に保存または共有。
  • 取り込み：以前のJSONファイルから復元。現在のデータをすべて上書きするため、事前にバックアップしてください。

12.2 無料会員は「本人」の薬箱のみバックアップ

無料会員は薬箱が1つなので、出力・取り込みはその1つの薬箱のみが対象です。注意：既定の薬箱を改名しても（例：「本人」→自分の名前）、出力・取り込みは現在のその1つの薬箱が対象で、名前には影響されません。複数薬箱のバックアップにはPROが必要です。

12.3 iCloudバックアップ（PRO）

「設定 → iCloud同期 → データバックアップ」：

  • 今すぐバックアップ：iCloud Driveへ手動バックアップ。
  • 復元：左スワイプ → 復元。
  • 削除：左スワイプ → 削除。
  • 共有：右スワイプ → 共有・保存。

1台あたり最大 20件のバックアップを保持し、超えると最も古いものを自動削除。

12.4 iCloud自動同期（PRO）

同じiCloudにサインインした端末間で薬と設定を自動同期。自動同期に端末数の制限はありません。「20件」は各端末のバックアップスナップショット数のみを指します。

12.5 復元・リセットの注意

  • 「復元」は現在のデータをすべて上書きするため、事前にバックアップを推奨。
  • 「ローカルデータ消去」は取り消しできません。
⚠️ データがない場合はバックアップファイルを生成せず、無効な空ファイルを避けます。

14. 設定とクラッシュログ

14.1 主な設定

  • テーマ色／文字サイズ／外観：ライト・ダーク・システムに従う。
  • 言語：簡体字中国語／繁体字中国語／English／日本語／システムに従う。
  • 通知：スマートオフセット、薬品名を隠す、在庫不足通知、バッジ表示。
  • データ消去：薬箱と薬を消去（記録は保持）または全ローカルデータを消去（復元不可）。

14.2 クラッシュログとは？

アプリが予期せずクラッシュすると、原因調査用の技術ログが自動的に端末内へ保存されます。このログには薬品名や用量などのプライバシー情報は含まれません（自動で匿名化されています）。「設定 → クラッシュ送信」で確認・コピーし、開発者に送っていただくと、問題の早期解決に役立ちます。送信しない場合、ログは端末内に保存されるだけで、自動アップロードはされません。
