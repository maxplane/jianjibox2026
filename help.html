1. 快速上手（首次使用）

第一次打开 App，你会依次看到 5 页引导介绍。右上角可点「跳过」，最后一页点「开始使用」进入主界面。

1
允许通知：首次添加药品时会弹出「通知」请求，请点「允许」。用药提醒依赖此权限。
2
确认药箱：系统已为你建好「本人」药箱，可直接用，也可改名。
3
添加药品：底部切到「药箱」页 → 点右下角「+」→ 拍照或手动录入。
4
开始打卡：到用药时间，「今日」页会出现待办，点一下即可打卡。
💡 底部三个标签：今日（当天打卡）、药箱（管理药品）、数据（历史与统计）。

2. 药箱管理

「药箱」用来给家人或不同场景分组管理药品，各药箱互不影响。

2.1 切换药箱

「药箱」页顶部标签栏左右滑动切换；点某个标签进入该药箱。

2.2 管理药箱

点左上角「管理」：

  • 新建：点「+」新建，输入名称。
  • 重命名：点药箱右侧编辑图标。
  • 关闭（封存）：临时停用药箱，药品与提醒暂停，可随时重开。
  • 删除：删除药箱，药品移入「回收站」。
💡 免费会员 1 个药箱；PRO 会员最多 10 个。
⚠️ 关闭药箱后提醒停止，重开后自动恢复。

3. 添加药品

3.1 两种方式

  • 拍照识别：拍药盒，自动识别药名/剂量/单位。
  • 手动录入：手动填写。

3.2 信息字段

  • 药品名称：必填。
  • 自定义名：可选别名，如「老爸的降压药」。
  • 规格 / 厂家 / 照片：可选。
  • 有效期：用于临期提醒。

3.3 用法用量

  • 每次用量 + 单位：如 1 片 / 5 毫升。
  • 用药时间：如 08:00、20:00。
  • 用餐要求：餐前 / 餐后 / 无要求 / 遵医嘱。

3.4 起止日期

设「开始日期」和「结束日期」，药品按疗程自动开始/停止提醒。

💡 免费会员最多 3 款药品、1 个提醒；PRO 不限。

4. 库存与批次管理

「批次」指同一药品不同批次的库存，每批可有不同的有效期和用法用量。

4.1 添加库存

添加药品时填「库存数量」和「有效期」即创建第一批；之后在药品详情页「补充库存」加新批次。

4.2 先到期先用

系统自动按「有效期最早」扣减库存，先到期先用。

4.3 批次级用法覆盖

可为某批次单独设置用量/时间。切到新批次时，提醒用量自动跟着变。

⚠️ 当前批次用完且下一批用法不同时，会弹提示告知「用药时间/用量已改变」。
💡 库存剩最后 1 次用量、或批次 7 天内到期，会有临期/低库存提醒。

5. 用药提醒

5.1 通知权限

请在系统「设置 → 通知 → 简记药箱」允许通知。

5.2 智能偏移提醒

开启后通知在设定时间附近随机浮动，打破疲劳记忆。范围可调（5/10/15/30 分钟），也可关闭。

5.3 稍后提醒

通知弹出后点「稍后提醒」，15 分钟后再提醒。

5.4 锁屏隐私

「设置 → 通知」开启「隐藏药品名称」，锁屏不显示药名。

6. 今日打卡

「今日」页按时间列出当天所有待办。打卡状态由实际时间自动判定：

  • 按时：计划时间 ±30 分钟内。
  • 提前：早于计划 30 分钟以上。
  • 延后：晚于计划 30 分钟以上。

6.1 打卡方式

  • 单条打卡：点待办 → 点「打卡」。
  • 一键打卡：点顶部「一键打卡」批量完成。

6.2 其他操作

  • 跳过：本次不吃（不扣库存）。
  • 忘记：忘记吃（不扣库存）。
  • 忽略：左滑忽略某条（不计入统计）。
⚠️ 打卡自动扣库存；库存不足一次用量会拦截并提示补货。
💡 误操作可到「数据 → 打卡记录」重新打卡/删除，会自动退回库存。

7. 历史记录与统计

7.1 打卡记录

按天查看，顶部月历可跳转。点记录可：补录、重新打卡、删除、标记忘记。

7.2 用药统计

饼图 + 总打卡 / 药品种类 / 按时率 / 批次消耗 / 打卡时段分布。可切「本月 / 本年 / 全部」。

7.3 导出报表（PRO）

导出 PDF 用药报告。

8. 数据备份与恢复

8.1 本地备份（JSON）

「设置 → 本地数据备份」：导出 JSON 文件 / 导入恢复（覆盖当前数据）。

8.2 iCloud 数据备份（PRO）

「设置 → iCloud 同步 → 数据备份」：

  • 立即备份：手动创建一份备份到 iCloud Drive。
  • 恢复：左滑某份备份 → 点「恢复」。
  • 删除：左滑某份备份 → 点「删除」。
  • 分享：右滑某份备份 → 点「分享」，把备份文件分享/保存到其他 App。

每台设备最多保留 20 份备份，超出后自动删除该设备最旧的。

设备同步说明：iCloud「自动同步」数据没有设备数量限制——只要登录同一个 iCloud 账号，所有设备都会同步。上面的「每台设备 20 份」仅指 iCloud Drive 里的备份文件快照，按设备区分、各自保留。

8.3 iCloud 自动同步（PRO）

开启后，换设备或重装，登录同一 iCloud 账号即自动同步药品与设置。

⚠️ 免费会员仅支持导出/导入「本人」药箱；多药箱备份需 PRO。
💡 删除 App 会清空本地数据；开 iCloud 同步或提前导出备份可避免丢失。

9. PRO 会员

PRO 解锁：多药箱（10 个）、不限药品/提醒、多张照片、导出报表、iCloud 同步与云备份、更多主题色、后续功能免费更新。

9.1 购买 / 兑换 / 恢复

付费墙底部：

  • 立即解锁：App Store 内购。
  • 我有兑换码：输 8 位兑换码。
  • 恢复购买（兑换）：找回已购/已兑换的 PRO。
💡 恢复购买需联网（Wi-Fi 或蜂窝）。

10. 设置与个性化

  • 主题色 / 文字大小 / 外观模式（浅/深/跟随系统）。
  • 语言：简体 / 繁體 / English / 日本語 / 跟随系统。
  • 通知：智能偏移、隐藏药名、低库存提醒。
  • 清空数据：清空药箱与药品（保留记录）或清空全部本地数据（不可恢复）。

11. 常见问题与注意事项

11.1 数据存哪？

默认仅存设备本地；开 iCloud 同步（PRO）后经你自己的 iCloud 私密同步。

11.2 不联网能用吗？

能。药品管理/打卡/提醒/统计/本地备份都无需联网；仅 iCloud 备份同步、兑换码、内购/恢复购买需网络。

11.3 打卡影响库存吗？

会，打卡自动扣一次用量；删除/重置记录自动退回。

11.4 提醒没响？

  • 检查系统通知权限；
  • 检查药品是否「在用」（停用/关药箱会暂停提醒）；
  • 检查用药时间。

11.5 免责声明

⚠️ 本 App 仅用于用药记录与提醒，不构成医疗建议，请遵医嘱。

1. Quick Start (First Use)

On first launch you'll see 5 intro pages. Tap "Skip" (top right) or "Get Started" on the last page.

1
Allow Notifications — tap "Allow" when prompted; reminders depend on it.
2
Confirm your box — a "Me" box is pre-created; you can rename it.
3
Add a medication — tap the "Medbox" tab → "+" → photo or manual entry.
4
Punch in — when it's time, the "Today" tab shows pending doses; tap to log.
💡 Three tabs: Today (punch-in), Medbox (manage meds), Data (history & stats).

2. Medbox (Pill Box) Management

2.1 Switch boxes

Swipe the top tab bar in the "Medbox" tab.

2.2 Manage boxes

Tap "Manage" (top left):

  • New — tap "+".
  • Rename — tap the edit icon.
  • Close (archive) — pauses that box; reopen anytime.
  • Delete — moves meds to Recycle Bin.
💡 Free: 1 box. PRO: up to 10 boxes.

3. Adding a Medication

3.1 Two ways

  • Photo OCR — snap the package, auto-detects name/dose/unit.
  • Manual — type everything.

3.2 Fields

  • Name (required), Custom name, Spec / Manufacturer / Photos (optional), Expiry.

3.3 Dosage

  • Amount + unit (e.g. 1 tablet / 5 mL), Times (e.g. 08:00, 20:00), Meal (before/after/none).

3.4 Start / End dates

Set dates for course-based auto start/stop.

💡 Free: 3 meds, 1 reminder. PRO: unlimited.

4. Stock & Batch Management

Batches let the same med have different expiry and dosage.

4.1 Add stock

Enter "Stock" + "Expiry" when adding; later use "Restock" in details.

4.2 First-expiry-first (FIFO)

The earliest-expiry batch is consumed first.

4.3 Per-batch dosage override

A batch can override dosage/time; reminders update automatically when the batch switches.

⚠️ When the current batch runs out and the next differs, you'll be notified that time/dosage changed.

5. Reminders

5.1 Notification permission

Enable in iOS Settings → Notifications → JianjiBox.

5.2 Smart offset

Reminders drift slightly around the set time (range 5/10/15/30 min, or off).

5.3 Snooze

Tap "Snooze" on a notification to remind again in 15 min.

5.4 Lock-screen privacy

Enable "Hide med name" to not show names on lock screen.

6. Punching In (Today)

Status is auto-judged by actual time: On time (±30 min), Early, Late.

6.1 How

  • Single: tap a pending item → "Punch".
  • Punch all: tap "Punch all" at top.

6.2 Other actions

  • Skip (no stock deduction), Forgot, Ignore (swipe left; excluded from stats).
⚠️ Punching deducts stock. If insufficient, you'll be asked to restock.
💡 Mistakes can be fixed in Data → History (re-punch/delete auto-returns stock).

7. History & Statistics

7.1 History

Day view with a month calendar. Tap a record to re-punch, delete, or mark forgotten.

7.2 Stats

Pie chart + total punches / med types / on-time rate / batch consumption / time distribution. Switch "This month / This year / All".

7.3 Export report (PRO)

Export a PDF medication report.

8. Backup & Restore

8.1 Local backup (JSON)

Settings → Local Data Backup: export a JSON file / import to restore (overwrites current data).

8.2 iCloud backup (PRO)

Settings → iCloud Sync → Data Backup:

  • Backup now — create a backup to iCloud Drive.
  • Restore — swipe left on a backup → "Restore".
  • Delete — swipe left → "Delete".
  • Share — swipe right → "Share" to save/share the backup file.

Each device keeps up to 20 backups; the oldest is auto-deleted.

Device sync: iCloud auto-sync has no device limit — any device signed into the same iCloud account syncs. The "20 per device" only refers to iCloud Drive backup snapshots, kept per device.

8.3 iCloud auto-sync (PRO)

Turn on to auto-sync meds & settings across devices.

⚠️ Free: only "Me" box export/import. Multi-box backup needs PRO.

9. PRO Membership

PRO unlocks: multiple boxes (10), unlimited meds/reminders, multiple photos, PDF report export, iCloud sync & backup, more themes, free future updates.

9.1 Purchase / Redeem / Restore

  • Unlock now — App Store purchase.

  • Restore purchase (redeem) — recover prior PRO.

10. Settings & Personalization

  • Theme color / Text size / Appearance (light/dark/system).
  • Language: 简体 / 繁體 / English / 日本語 / System.
  • Notifications: smart offset, hide med name, low-stock.
  • Clear data: clear boxes & meds (keep records) or clear all local data (irreversible).

11. FAQ & Notes

11.1 Where is data stored?

Locally on device by default; with iCloud sync (PRO), synced privately via your own iCloud.

11.2 Works offline?

Yes — meds, punch-in, reminders, stats, local backup all work offline. Only iCloud backup/sync, redeem, purchase/restore need network.

11.3 Does punching affect stock?

Yes, punching deducts one dose; delete/reset auto-returns it.

11.4 Reminder not firing?

  • Check notification permission;
  • Check the med is active;
  • Check the scheduled time.

11.5 Disclaimer

⚠️ This app is for tracking & reminders only, and is not medical advice. Follow your doctor's instructions.
